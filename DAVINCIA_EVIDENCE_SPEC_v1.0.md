# DAVINCIA⁺ EVIDENCE SPECIFICATION v1.0

Every significant lifecycle state change, validation pass, or evaluation outcome must produce an immutable, append-only evidence record.

---

## 1. Append-Only Ledger Principle
Ecosystem governance records are never overwritten. Mutations increment object versions and append a transition trace log to the historical audit block.

---

## 2. Evidence Types
* `DISCOVERY_RECORD`: Ingest validation log.
* `PROFILE_RECORD`: Assigned classifications.
* `POLICY_PROPOSAL_RECORD`: Proposed rulesets.
* `CONFORMANCE_RECORD`: Conformance harness scorecard results.
* `AUTHORIZATION_RECORD`: Human signature approvals.
* `DRIFT_RECORD`: Manifest change triggers.
