## 1. Executive Summary: The Best Open-Source Voice Stack

> [!IMPORTANT]
> **Core Architectural Answer**:
> "What is the best available open-source technology stack for turning Alex Wenger² governed state into spoken interaction?"
> 
> The winning architecture is a **Unified Modular Multi-Engine Voice Pipeline**:
> 1. **VAD (Voice Boundary & Barge-in)**: **Silero VAD v5** (MIT, <1ms chunk latency, ONNX/JS runtime).
> 2. **STT (Speech-to-Text)**: **Sherpa-ONNX + Moonshine/Whisper-ONNX** (Apache 2.0 / MIT, offline CPU real-time streaming).
> 3. **TTS (Text-to-Speech)**: **Kokoro-82M ONNX** (Primary Quality/CPU, Apache 2.0) + **Piper ONNX** (Low-Latency Fallback, MIT).
> 4. **Transport**: **Opus Codec over WebRTC DataChannel / Streaming Ring Buffer** (<100ms round-trip).
> 5. **Fallback Tier**: Native **Web Speech API** (`SpeechRecognition` / `speechSynthesis`) for zero-install browser resilience.
